# Attribution

Sentinel was created and is maintained by DarienRam. This source release retains the project's original application design, rule engine and user interface, with security and compatibility maintenance. Existing legitimate third-party notices must be preserved.

The landing-page chart cites the Federal Trade Commission's Consumer Sentinel Network Data Book 2024. Its annual totals cover consumer reports across fraud, identity theft and other consumer-protection concerns, not all scam attempts. Source: https://www.ftc.gov/reports/consumer-sentinel-network-data-book-2024.

Demonstration text, contact-like fixtures and screenshots are synthetic. The example phone uses the reserved North American 555-01xx fiction range; the example IPv4 address is in TEST-NET-1. No external message corpus, dataset or model is distributed.

Runtime and development packages retain their own upstream licenses. Dependency metadata and license review are recorded during release validation. A project license decision applies only to material the owner has rights to license.
