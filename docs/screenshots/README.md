# Sentinel Screenshot Capture Guide

Capture these five desktop screenshots for the public README. Use the browser
window without personal account details visible. A 16:10 desktop viewport is
ideal, and browser chrome is optional as long as the product is clear.

Save each image in this folder with the exact name below:

1. `01-landing-page.png` — landing page with the hero and FTC chart visible.
2. `02-analyze-high-risk.png` — completed high-risk URL, email, or message
   result with score, recommendation, and category chips visible.
3. `03-scan-report.png` — a full report showing the summary, evidence cards,
   and at least one detailed finding.
4. `04-dashboard.png` — dashboard with populated history, filters, and the
   time-window comparison visible.
5. `05-safety-guide.png` — Safety guide showing the three-step visual or the
   example cards.

Do not include a signed-in username, email address, real messages, access
tokens, local paths, or other personal information. Use the app's built-in
sample-style inputs or sanitized examples instead.
